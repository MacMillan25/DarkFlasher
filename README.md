# Dark Flasher 1.4.1 👾

Прошивалка для нод **DarkTec** на nRF52840: выбираешь роль и версию прошивки, заполняешь настройки — программа сама скачивает файл, прошивает и записывает настройки в ноду по USB.

![Dark Flasher](preview.png)

## Что умеет

- **8 ролей**: Companion (BLE/USB), Repeater, Repeater + RS232, Room server, Sensor + GPS, Terminal chat, KISS modem.
- **Версии прошивок** берёт из релизов GitHub — показывает пять последних сборок начиная с d7, скачивает нужную.
- **Список обновляется сам** — примерно раз в полчаса (без жёсткого таймера). Локальные dev-сборки подхватываются сразу, как только изменилась папка, и работают без GitHub/интернета.
- **«Что нового»** — кнопка рядом с версией: открывает заметки из релиза GitHub. Если с прошлого запуска вышла новая прошивка, кнопка подсвечивается оранжевым.
- **Проверяет sha256** скачанного файла, чтобы не прошить битый.
- **Собирает файлы с вшитыми настройками**: «Собрать UF2 с настройками» и «Собрать OTA-ZIP с настройками». Программа
  вписывает в образ блок заводских настроек (метка `DARKTEC-FACTORY`, имя, канал, мощность,
  ёмкость, модуль), и прошивка при первом старте применяет их сама. UF2 — для обычной
  прошивки, zip — для обновления по воздуху (bootloader OTAFIX, приложения Nordic DFU).
  Готовый файл ложится в подпапку `built` рядом с прошивкой, путь пишется в лог оранжевым.
- **Пишет настройки в ноду**: имя, канал (частота/полоса/SF/CR), мощность, ёмкость батареи, радиомодуль, коэффициент АЦП.
- **Галочки у настроек**: что выключено — то не уходит на ноду и не вшивается в UF2/OTA. У радио (частота, полоса, SF, CR) одна общая галочка, у мощности и радиомодуля — свои.
- **LR2021**: для такой сборки отключается только радиомодуль; частота, мощность и остальные настройки остаются.
- **Один прогресс** на всю операцию: скачивание → прошивка → настройки.
- Помнит настройки между запусками — в exe они лежат в `%APPDATA%\DarkFlasher\darkflasher.json`, при запуске из исходников — в `darkflasher.json` рядом с проектом. Старый файл рядом с exe подхватывается при первом запуске.
- Ссылки на группу, покупку нод, прошивки beeline09 и документацию — внизу окна.

## Как прошить

1. Скачай [последний релиз](https://github.com/MacMillan25/DarkFlasher/releases/latest) и положи `DarkFlasher.exe` в любую папку.
2. Запусти `DarkFlasher.exe`.
3. Выбери **роль** и **версию** прошивки.
4. Проверь настройки: имя, канал, мощность, ёмкость, модуль. Если имя оставить пустым — оно не изменится.
5. Нажми **ПРОШИТЬ**.
6. Плату переведи в загрузчик: **быстро нажми RESET два раза**. Появится диск `NRF52BOOT` — программа поймает его сама.
7. Дальше всё автоматически: запись → перезагрузка → поиск ноды по COM → отправка настроек.

Если плата уже в загрузчике — программа начнёт сразу.

### Что означают статусы

| Статус | Значение |
|---|---|
| `BOOT · можно прошивать` | плата в загрузчике, виден UF2-диск |
| `COM5 · нода на связи` | плата работает, порт найден, настройки можно писать. Если nRF-портов несколько, у статуса есть `▾` — по клику выбирается нужный |
| `НЕТ ПЛАТЫ` | ничего не подключено |

### Если что-то не так

- **«нода не ответила ни на одном порту nRF»** — проверь кабель и что нода не в загрузчике. Настройки не отправились, прошивка при этом уже записана.
- **SmartScreen** — «Подробнее» → «Выполнить всё равно».
- Настройки на некоторых ролях (Terminal chat, KISS modem) пока не поддерживаются — они не понимают CLI.

## Где лежат прошивки

- Скачанные из GitHub — в `%APPDATA%\DarkFlasher\firmware\<env>.uf2`.
- Рядом с exe тоже читается папка `firmware` — можно положить файл вручную.
- Если выбрал файл вручную (клик по зоне или перетаскивание), в списке версий появляется пункт «файл вручную»: шьётся именно он, настройки после прошивки не отправляются.

## Сборка

`build.cmd` — соберёт `dist\DarkFlasher.exe` (Python 3.10+, PyQt6, PyInstaller, pyserial).
Из исходников — `Запуск.bat` (запускает `darkflasher_qt.py`).
