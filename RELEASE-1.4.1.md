# Dark Flasher 1.4.1

Windows 10/11 x64. Техническое обновление: исправления логики, потоков и интерфейса. Новых ролей и прошивок нет.

**Установка:** скачай `DarkFlasher.exe` и положи в любую папку. Настройки и скачанные прошивки при первом запуске появятся в `%APPDATA%\DarkFlasher`; старый `darkflasher.json` рядом с exe подхватится автоматически.

![Dark Flasher 1.4.1](https://github.com/MacMillan25/DarkFlasher/raw/main/preview.png)

## Главное

- **Выбранный вручную .uf2 больше не игнорируется.** Клик по зоне выбора или перетаскивание файла добавляет пункт «файл вручную»; «Прошить» и «Собрать» работают именно с ним. Если выбран релиз GitHub, локальный файл из `firmware` не подставляется молча.
- **«Прошить» больше не может незаметно превратиться в «Собрать».** Назначение загрузки передаётся вместе с событием, а не хранится в общем флаге.
- **Настройки не считаются отправленными, если нода не ответила.** Нет ответа хотя бы на одну команду — ошибка, `reboot` не отправляется, финальная фраза не врёт.
- **Порт проверяется как MeshCore.** Выбранный COM пробуется первым, но принимается только после реального ответа; чужая nRF-плата не получает команды.
- **Ошибка скачивания/записи больше не вешает окно навсегда.** `busy` снимается, `.part` удаляется, причина в логе.
- **Закрытие во время операции спрашивает подтверждение.**
- **Настройки и прошивки в exe лежат в `%APPDATA%\DarkFlasher`**, а не рядом с exe. Работает из Program Files; старый `darkflasher.json` рядом с exe подхватывается.
- **Один экземпляр:** второй запуск показывает предупреждение.
- **Dev-режим не зависит от GitHub:** если интернет/VPN недоступны, список локальных сборок из папки Dev остаётся и выбирается; сообщение о сети становится предупреждением, а не красной ошибкой.

## Прошивка и файлы

- Ложный успех при ошибке последнего блока убран; UF2 из одного блока больше не проходит по «последнему блоку».
- Переставленные блоки UF2 принимаются (порядок блоков в файле не важен).
- Ограничение размера образа и проверка непрерывности адресов — битый UF2 не может выделить сотни мегабайт.
- Имя ноды обрезается по границе UTF-8, а не посередине символа.
- Проверяются диапазоны частоты, полосы, SF, CR, мощности, ёмкости и модуля.
- OTA не собирается из образа с чужой базой; хвост образа выравнивается по 4 байта.
- Результаты сборки кладутся в подпапку `built`, чтобы не попадать в список прошивок.

## Интерфейс

- Окно открывается по высоте содержимого; при обычном размере прокрутки нет. Если уменьшить окно вручную — появляется прокрутка, чтобы низ не пропал.
- У выпадающих списков убраны стрелки: они остаются чистыми полями, как раньше.
- Поля настроек подсвечиваются красным при неверном значении; операция не стартует, пока ошибка не исправлена.
- Кнопки, роль, версия и настройки блокируются на время операции.
- Статус и версии «Собрать UF2» больше не называют OTA-пакетом; CRC32 подписан как CRC32.
- Чекбоксы получили доступные имена для экранного диктора.

## Уборка

- Удалён 552-строчный дубль ядра и старый Tk-интерфейс из `DarkFlasher.py`.
- Удалены мёртвые `send_commands`, `fetch_manifest`, `build_dfu_zip` и неиспользуемые поля.
- `build.cmd` использует `python -m PyInstaller` и сообщает об ошибке сборки.
