Dark Flasher 1.2 — прошивалка нод DarkTec.

Что нового:

- **Кнопка «Собрать OTA-ZIP»** — рядом с «Прошить» и «Отправить настройки».
  Выбираешь роль и версию, жмёшь — программа собирает стандартный Nordic DFU
  пакет из прошивки: разбирает `.uf2`, склеивает образ, считает CRC16 и
  упаковывает `firmware.bin` + `firmware.dat` + `manifest.json` в zip.
- **Готовый пакет понимает bootloader OTAFIX** и приложения Nordic DFU
  (nRF Connect Device Manager, dfu.py). То есть ноду можно обновлять по воздуху,
  не снимая с крыши.
- Если нужной версии прошивки нет локально, она скачается сама — с прогрессом
  в статус-баре, как при обычной прошивке.
- В логе видны все шаги сборки, а строка с путём к готовому файлу выделена
  оранжевым: `firmware/<роль>-ota-<дата>_<время>.zip`.
- Версия 1.2.

Важно: настройки (имя, канал, мощность, ёмкость, модуль) внутрь OTA-пакета
не попадают — по воздуху едет только прошивка. Настройки на ноде при
обновлении сохраняются; если их нужно поменять, это делается по USB кнопкой
«Отправить настройки».
